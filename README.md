# Dopamine — визуальная демонстрация

Интерактивный макет: айфон на вебе и пошаговый сценарий
**блокировка → рабочий стол → Dopamine → джейлбрейк → выбор пакетов →
установка → новые иконки → менеджер пакетов**.

Чистый HTML/CSS/JS. Без сборки, зависимостей и сети — просто открой
`site/index.html` в браузере.

Опубликовано: <https://no-recovery.github.io/jb-demo>

## Файлы

| Файл       | Назначение                                            |
|------------|-------------------------------------------------------|
| `site/index.html` | Разметка телефона, экранов и SVG-спрайт иконок  |
| `site/styles.css`| Корпус iPhone, обои, экраны, анимации           |
| `site/app.js`| Шаги сценария, данные пакетов, машина состояний     |
| `site/.nojekyll`| Отключает Jekyll на GitHub Pages                 |
| `check.ps1` | Автотест: рендерит страницу в Chrome и сверяет DOM    |
| `shots/`    | Скриншоты всех девяти шагов                            |
| `.github/workflows/pages.yml` | Деплой `site/` в ветку `gh-pages`      |

Исходники лежат в `main`, сайт раздаётся с ветки `gh-pages` — так же, как
в [wipecode](https://github.com/No-Recovery/wipecode).

## Управление

Кнопки **«Назад» / «Далее»** под телефоном. Плюс:

- чипы над кнопками — переход на любой шаг сразу;
- значок **Dopamine** на рабочем столе кликабелен;
- кнопка **«Джейлбрейк»** в приложении запускает процесс;
- пакеты на шаге 5 отмечаются и снимаются кликом;
- на последнем шаге кнопка становится **«Заново»** и сбрасывает сценарий.

Прямая ссылка на шаг: `index.html#jbdone`, `index.html#manager`,
`index.html#4`. Изменение адреса тоже переключает шаг.

## Пакеты

По умолчанию отмечены **Sileo** (менеджер пакетов) и **WipeCode** (твик).
Менеджером считается первый отмеченный пакет с типом «Менеджер пакетов» —
его заголовок появляется в списке установленного, а иконка — на рабочем столе.

## Тесты

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\check.ps1
```

Скрипт гоняет Chrome в headless по всем девяти шагам и проверяет: нет ошибок
JS, активен нужный экран, списки отрисованы, счётчики и подписи верны.
Код возврата — число провалов.

## Замечание

Это визуальный макет, а не эмулятор. Реальный джейлбрейт в облачном
эмуляторе (например, Appetize) невозможен: там нет настоящего ядра iOS,
а bootstrap rootless-подсистемы на нём не поднимается.
